À propos

Movie Explorer est une plateforme d'affichage de films réalisée dans le cadre de l'atelier Git.

Son objectif est de parcourir un catalogue de films, de collaborer avec Git et GitHub, et de découvrir comment plusieurs personnes font évoluer le même projet.

L'application affiche des cartes de films (titre, année, genre, note, réalisateur) à partir d'un fichier JSON, dans une interface simple en HTML, CSS et JavaScript.

Technologies utilisées : HTML, CSS, JavaScript et Git / GitHub.
